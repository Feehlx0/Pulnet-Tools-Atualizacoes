# Pulnet Tools — atualizações

Este repositório guarda apenas os instaladores publicados do **Pulnet Tools**, da Pulnet Tecnologia.

O próprio app consulta esta página quando você clica em **Configurações → Sobre → Verificar atualizações**. Antes de instalar, o app confere se o arquivo baixado é exatamente o publicado aqui (impressão digital SHA-256).

Para instalar pela primeira vez, baixe o arquivo `PulnetTools-Setup-<versão>.exe` da versão mais recente em **Releases**.
